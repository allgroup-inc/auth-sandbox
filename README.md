# auth-sandbox — 人間とAIのGitHub権限分離の試験場

このリポジトリは、**AI専用アカウントが `main` を承認・統合できないこと**を確かめるための試験場です。
本番のデータ・コード・個人情報は置きません。試験が終わったら、保存庫に入れるか削除します(削除は小柳さんの承認で)。

- 基準: hojo-hq の決裁26(議事 docs/議事/議事_20261008_決裁26_Rulesets段階導入.md)
- 段階A: 公開リポジトリ(GitHub Free)で、6つの拒否試験を行う
- 段階B: Team プランに上げた後、非公開に切り替えて同じ試験を行う(未承認)
- 試験の記録: `TESTS.md`
